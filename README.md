# NekPhysalis

Research implementation of the Physalis method
using two spectral-element CFD solvers.

## Implementations

- `nek5000-2d/`: 2D axisymmetric Nek5000 implementation
- `nekrs-3d/`: 3D NekRS implementation

## Reproducibility status

This repository is a preliminary source snapshot.

The 2D core is taken from the selected case's
build-directory snapshot.

The 3D solver source is the Stage5C-H2 candidate.
Its exact correspondence to the Re100 runtime
installation has not yet been established.

Upstream dependencies, build paths, software licenses,
and clean-build reproducibility must be reviewed
before public release.
